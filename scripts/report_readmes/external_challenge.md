Regenerated by `python -m scripts.build_external_figures`. Derived from the external run
directory and the internal runs it compares against; safe to delete.

**Route B. The generator is `astra_mediated_unidentified` and cannot be named.** No figure
or number here supports an architectural claim. The evaluation set is 200 images (100
generated + 100 authentic), the pre-registered *minimum reportable* tier: not the
recommended 250-per-class tier that would match the internal unseen test's resolution.

A detector with no number for an evaluation set is annotated `not measured` rather than
drawn as a zero bar: the all-seven-generators baseline has no held-out generator, so it has
no unseen row.

## Interpretation

The saved external scores exceed the held-out VQDM scores. This does not establish
that detection difficulty depends on generator recency: the external generator is
unidentified and the evaluation covers one small image set.

Native resolution and photographic style remain uncontrolled. The generated
images were downscaled from 1254px, and their style differs from the ImageNet-derived
authentic pool. These differences could contribute to the scores despite identical
output preprocessing. Report these limits alongside the external results.

External recovery was not run. Recovery and ablation cells retained checkpoint
digests but removed their weights, so adapted detectors would need to be refitted.
